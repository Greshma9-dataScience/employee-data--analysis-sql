# employee-data--analysis-sql
SQL-based employee data analysis project using MySQL, joins, aggregations, CASE statements, and business reporting.


Employee Data Analysis Using SQL

Project Overview

This project analyzes employee data using SQL to generate useful business insights about salaries, departments, job roles, and locations.

Tools Used

- MySQL
- MySQL Workbench
- SQL

Key SQL Concepts

- SELECT, WHERE, ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- CASE Statements
- Subqueries

Business Questions

1. How many employees are in the company?
2. What are the average, minimum, and maximum salaries?
3. Which department has the most employees?
4. Who is the highest-paid employee?
5. How do salaries differ by department and city?
6. Which employees earn above the company average?

Dataset

The project uses a fictional dataset of 10 employees across four departments: IT, HR, Finance, and Sales.

Objective

To practice SQL querying and demonstrate how employee data can support basic business reporting and analysis.
